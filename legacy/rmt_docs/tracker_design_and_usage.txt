Notes:

TRACKS EDITOR

When moving the cursor over the tracks in the "tracks editor", it indicates in color whether the
current instrument can be fully used in the current track - i.e. it is a FILTER and 16BASS instrument.

For example, if the current instrument has a FILTER and I am somewhere in track L1, the headings
TRACK_L1 and TRACK_L3 and the text FILTER will be highlighted GREEN. On the other hand, if I am with this instrument
somewhere in track L3, the heading TRACK_L3 and the text FILTER will be highlighted RED.
Similarly for 16BASS. In track 2, the headings TRACK_L2 and TRACK_L1 and the text 16BASS will be
highlighted GREEN, on the other hand, in track 1, TRACK_L1 and 16BASS will be highlighted RED.

The beat numbers displayed to the left of the track and LEN data for the song can be switched between DEC or HEX.

"Sensitive help" in the tracks editor. 
Principle for different language versions. 
( command {22 ..level $2}
            {33 ..level $3}
             {Hblablablabla} )    H is a one-digit Hex number, i.e. max. 0-f.


INSTRUMENT EDITOR

If I activate FILTER and DISTORTION==6 (16BASS), then DISTORTION will automatically change to C.
Similarly, if I set DISTORTION to 6 and filter is on, then filter will automatically turn off.

When moving through the items, "sensitive help" is displayed at the bottom and the relevant passages
are bolded according to the specific values ​​(for each help there is a BYTE field, which has one BYTE
for each character in the help, which determines the connection of this letter with the current value).

The volume envelope curve is displayed in one color until its end according to the length of the instrument,
then it is calculated according to the goto loop, VSLIDE and VMINIM and drawn faintly up to length 33
(one more than the maximum length of the instrument (32) - to see how it continues).
The left curve is drawn flat, the right channel is displayed in a different color and just as a line.
