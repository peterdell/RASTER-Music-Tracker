# Legacy

This folder contains files from the original RMT by Radek Sterba, Raster/C.P.U., 2002-2009.

It contains files for RMT 1.28 and earlier versions and is kept for legacy preservation and reference.

All historical versions of RMT are in the "others\Raster" subfolder.
All still-relevant content is also available in "rmt128" subfolders of the "rmt" folder in the project root.
