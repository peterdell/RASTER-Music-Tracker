# RMT Example Songs



The songs in the "rmt128" folder are compatible with RMT 1.28.

The songs in the "rmt134" folder require RMT 1.34 or newer.

`rmt134/buddy/Captain_Future_Theme.rmt` is also the master tune of the Simple
RMT Player: `asm/Patch-16/music.rmt` is its byte-identical bundle, and its
permanent SAP-R replay reference lives with the test fixtures in
`test-resources/songs/rmt134/captain_future_theme/` (see the README there).
