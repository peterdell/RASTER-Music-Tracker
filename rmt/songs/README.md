# RMT Example Songs



The songs in the "rmt128" folder are compatible with RMT 1.28.

The songs in the "rmt134" folder require RMT 1.34 or newer.

`rmt134/buddy/Captain_Future_Theme.sapr` is the permanent SAP-R reference of the tune
beside it: RMT's own register dump of one full, non-repeating pass (7524 stereo frames),
which `build/record_sapr_bridge.py` compares the Simple RMT Player's replay against
(plans/33_ALTIRRA_REPLAY_VERIFICATION_PLAN.md). Regenerate it with an rmtscript:
`open` the .rmt, then `export sapr Captain_Future_Theme.sapr date="13/08/2024"`.
